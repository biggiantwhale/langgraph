# 01. Google Sheets Automation

## 개요

소상공인, 학원, 병원, 쇼핑몰, 1인 사업자가 매출·고객·업무 현황을 구글시트로 관리할 수 있도록 자동화 구조를 설계하는 샘플입니다.

## 해결하려는 문제

기존 방식:

- 매출을 수기로 입력함
- 고객 정보를 여러 곳에 흩어져 관리함
- 월별 매출 합계를 직접 계산함
- 재방문 고객 확인이 어려움
- 사장이 매일 숫자를 다시 정리해야 함

개선 방식:

- 입력표 하나에만 기록
- 월별/고객별/상품별 매출 자동 집계
- 재방문 고객 자동 표시
- 일일/주간/월간 요약 가능
- ChatGPT 프롬프트와 연결해 분석 문장 생성 가능

## 기본 기능

- 매출 입력표
- 고객관리표
- 월별 매출 집계
- 상품/서비스별 매출 분석
- 재방문 고객 체크
- 미수금/결제상태 체크
- 일일 요약 프롬프트

## 예시 서비스 문구

엑셀이나 수기로 관리하던 매출·고객 정보를 구글시트로 자동 정리해드립니다.

월별 매출, 고객 목록, 재방문 체크, 결제 상태, 간단한 통계까지 한 화면에서 볼 수 있게 제작 가능합니다.

## 확장 가능성

- Looker Studio 대시보드 연결
- 카카오톡 상담 내용 정리
- 예약 관리 자동화
- 견적서 자동 생성
- 월간 보고서 자동 작성
