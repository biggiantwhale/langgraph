# 02. RFQ / Quote Automation

## 개요

견적 요청서(RFQ), 발주 문의, 고객 요청 내용을 정리해 견적서 작성 흐름을 빠르게 만드는 자동화 샘플입니다.

## 해결하려는 문제

기존 방식:

- 문의 내용을 사람이 매번 읽고 정리함
- 품목, 수량, 납기, 조건을 놓치기 쉬움
- 견적서 작성에 시간이 오래 걸림
- 고객별 요청 이력이 쌓이지 않음

개선 방식:

- 고객 요청 내용을 항목별로 구조화
- 품목/수량/납기/특이사항 자동 추출
- 견적서 초안 생성
- 고객별 문의 이력 관리
- 반복 견적 업무 시간 단축

## 기본 기능

- 문의 내용 분류
- 품목/수량/단가/납기 추출
- 견적서 초안 템플릿
- 고객별 RFQ 기록 관리
- 누락 정보 체크리스트
- 회신 메시지 초안 생성

## 예시 서비스 문구

이메일이나 카카오톡으로 들어오는 견적 요청 내용을 정리해, 품목·수량·납기·조건을 빠르게 확인할 수 있는 RFQ 관리표를 제작해드립니다.

견적서 초안과 고객 회신 문구까지 함께 정리할 수 있습니다.

## 확장 가능성

- Gmail 연동
- 구글시트 견적서 자동 생성
- PDF 견적서 출력
- 반복 고객 단가표 연결
- 미회신/진행중/완료 상태 관리
