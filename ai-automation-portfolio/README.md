# AI Automation Portfolio

AI, 업무자동화, 문서/데이터 정리, 구글시트 자동화, RFQ/견적 자동화 샘플을 정리하는 포트폴리오 공간입니다.

## 목적

이 저장소는 단순 코드 저장소가 아니라, 외주·취업·사업화를 위한 실전형 포트폴리오입니다.

핵심 방향은 다음과 같습니다.

- 반복 업무를 AI와 자동화 도구로 줄이기
- 엑셀/구글시트 기반 업무를 자동 집계 구조로 바꾸기
- 문서, 견적서, 고객문의, 매출 데이터를 정리하기
- 소상공인/중소기업이 바로 이해할 수 있는 샘플 만들기
- 향후 B2B 자동화 대행/컨설팅으로 확장하기

## 포트폴리오 원칙

1. 보여주기 쉬운 결과물 중심
2. 고객이 이해하기 쉬운 설명 중심
3. 코드보다 문제 해결 흐름 중심
4. Before / After 구조로 정리
5. 외주 제안서와 연결 가능하게 작성

## 대표 서비스 문구

소상공인·중소기업의 반복적인 엑셀, 문서, 고객문의, 견적 업무를 AI와 구글시트 기반 자동화 구조로 정리해드립니다.

매출관리, 고객관리, 견적서 정리, 문의 응대, 보고서 제작 등 반복 업무를 줄이고 한눈에 볼 수 있는 관리 시스템으로 바꾸는 것이 목표입니다.
