# 03. Document AI Workflow

## 개요

보고서, 공고문, 이메일, PDF, 회의록, 과제 자료 등을 AI로 요약·분류·정리하는 문서 자동화 워크플로우 샘플입니다.

## 해결하려는 문제

기존 방식:

- 긴 문서를 사람이 전부 읽어야 함
- 핵심 내용과 해야 할 일을 놓치기 쉬움
- 자료가 흩어져 재사용이 어려움
- 반복적인 문서 정리에 시간이 많이 듦

개선 방식:

- 문서 핵심 요약
- 해야 할 일 추출
- 항목별 분류
- 제출용/보고용 문장 정리
- 외주 응대 문구로 변환

## 기본 기능

- 긴 문서 요약
- 핵심 조건 추출
- 체크리스트 생성
- 보고서 초안 작성
- 이메일/카톡 답장 문구 생성
- 파일별 내용 비교

## 예시 서비스 문구

복잡한 문서, 공고문, 이메일, PDF 내용을 읽기 쉽게 요약하고, 해야 할 일과 제출 항목을 체크리스트로 정리해드립니다.

보고서 초안, 답장 문구, 자료 정리까지 함께 작업 가능합니다.

## 확장 가능성

- Google Drive 파일 정리
- Gmail 첨부파일 분석
- 회의록 자동 요약
- 구직활동 보고서 작성 보조
- 면접 준비 자료 정리
